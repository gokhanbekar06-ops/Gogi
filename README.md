# Shorts AI Studio

Turkce odakli Android Shorts uretim uygulamasi.

Ilk surum: prompttan hikaye taslagi, bes sahnelik storyboard, 3D/gercekci tarz secimi ve Android TTS ile sesli onizleme.

APK derlemesi GitHub Actions uzerinden yapilir. Actions sekmesinde Android APK is akisinin tamamlanmasini bekleyip artifact dosyasini indirebilirsiniz.

Not: Gercek yapay zeka video/gorsel uretimi, altyazi zamanlama ve MP4 disari aktarma sonraki gelistirme asamalaridir. API anahtarlari uygulamaya gomulmemelidir.
